# Personal Task Tracker

An Obsidian-based personal task management system.

## Overview

This repository contains a complete task tracking system designed for use with [Obsidian](https://obsidian.md/), featuring:

- **18 Active Tasks** imported from honey-do list
- **5 Completed Tasks** in the archive
- Organized by priority (High, Medium, Low) and category
- Individual task files with metadata, subtasks, and notes
- Central dashboard for quick overview

## Quick Start

1. Open this folder as an Obsidian vault
2. Start with **Task Dashboard.md** for an overview of all tasks
3. Read **How to Use This Vault.md** for detailed instructions

## Structure

- **Task Dashboard.md** - Main overview and task organization
- **Tasks/** - Individual task files (18 active tasks)
- **Templates/** - Task template for creating new tasks
- **Archives/** - Completed tasks archive
- **How to Use This Vault.md** - User guide
