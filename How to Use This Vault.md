# How to Use This Obsidian Task Tracker

Welcome to your personal task tracking system in Obsidian!

## Getting Started

### Main Dashboard
Open **[[Task Dashboard]]** to see:
- All active tasks organized by priority
- Tasks grouped by category
- Recently completed tasks
- Quick statistics

### Working with Tasks

#### Viewing a Task
Click on any task link in the dashboard to open the detailed task file. Each task includes:
- Metadata (status, priority, category, who added it)
- Description
- Subtasks checklist
- Notes section
- Related tasks
- Task history

#### Completing a Task
When you finish a task:
1. Open the task file
2. Change `status: active` to `status: completed`
3. Add the completion date: `completed-date: YYYY-MM-DD`
4. Check off all subtasks
5. Move the task details to the [[Archives/Completed Tasks|Completed Tasks]] archive
6. Update the [[Task Dashboard]] to remove it from active lists

#### Creating a New Task
1. Open [[Templates/Task Template|Task Template]]
2. Fill in the metadata fields
3. Save to the `Tasks/` folder with a descriptive filename
4. Add the task to [[Task Dashboard]]

### Organization Tips

#### Priority Levels
- **High** 🔴: Urgent or time-sensitive tasks
- **Medium** 🟡: Important but not urgent
- **Low** 🟢: Nice to have, can wait

#### Categories
Current categories:
- **Home**: Interior home improvements and setup
- **Household**: General maintenance and chores
- **Finance**: Budget and financial tasks
- **Auto**: Vehicle-related tasks
- **Other**: Miscellaneous tasks

Feel free to add new categories as needed!

### Folder Structure

```
Personal-tasks/
├── Task Dashboard.md          # Main overview
├── How to Use This Vault.md   # This file
├── Tasks/                     # Individual task files
├── Templates/                 # Task template
└── Archives/                  # Completed tasks
```

### Obsidian Tips

#### Links
Use `[[Task Name]]` to create links between tasks and notes.

#### Tags
Tasks are pre-tagged. Use tags to filter and search:
- `#task` - All tasks
- `#high-priority` - High priority items
- `#home`, `#household`, `#finance`, etc. - By category

#### Graph View
Use Obsidian's Graph View to visualize connections between related tasks.

#### Daily Notes (Optional)
Consider using Obsidian's Daily Notes feature to:
- Link to tasks you're working on each day
- Track progress over time
- Add context and notes about task completion
